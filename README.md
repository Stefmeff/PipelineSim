# Pipeline Simulation Tool
This simulation tool is made with Unity and aims at visualizing hardware pipelines. In contrast to other available logic simulators, this tools allows to simulate the timing behaviour
of digital circuits. The user can build circuits from scratch and enter important timing parameters of components, such as propagation delays, setup and hold times, clock period, etc. and see how these parameters
affect the circuits overall behaviour and which timing constraints need to be adhered, for the design to work as intended.

When dealing with pipelines where there are multiple instructions/tokens in the hardware at the same time, it is also important to distinguish the different tokens.
